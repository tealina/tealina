# Add an endpoint to the scaffold templates

Use this when adding or changing a demo route under
`packages/create-tealina/template/api-v1/**/src/api/`. Read `AGENTS.md` first.

## The three trees

A route exists once per framework, in the `api-v1` package's tree:

```
template/api-v1/{express,fastify,koa}/src/api/<method>/<route>.ts
```

The three are the same route against three frameworks. The handler body differs only where
the framework's request and response types differ — express's `res.send`, koa's
`ctx.body`, fastify's `reply.send`.

## Steps

1. Pick the method directory (`get/`, `post/`, …) and write the handler in **all three
   trees**: `const handler: OpenHandler<Payload, Response> = …` then
   `export default openApi(handler)` (or `authedApi`).
   - Use `interface` for payload shapes, not inline object types: the document generator
     records the declaration name.
   - JSDoc comments become API documentation; `//` comments do not.
2. Update the barrels in each tree. `create` copies them as-is; it does not run `align`, so a
   handler missing from the barrel is silently unrouted in scaffolded projects.
   - `src/api/<method>/index.ts` gets one line alongside the existing ones.
   - `src/api/index.ts` only changes for a new method directory.
   - Keep the generated header (`// @generated by tealina — do not edit.`) and sorted keys.
3. If the route adds a file, name it in `src/template-manifest.ts` (`kApiV1SourceFiles` names
   the route tree; the manifest is the only list of shipped files). The file is copied into
   `backend/api-v1` for every framework.
4. If the route changes what the scaffolded demo needs (for example a payload type), keep the
   web demo page in step (`template/web/src/main.ts` calls `req.get('health')`).
5. Verify:

   ```bash
   vp check
   pnpm -F create-tealina test
   TEALINA_E2E=1 pnpm -F create-tealina test   # slow; real install and request
   ```

   `test/template-parity.test.ts` will fail if one framework's tree is missing a file;
   `test/template-manifest.test.ts` will fail if the manifest and template disagree.
6. If the endpoint changes what users see in a generated project, add a changeset for
   `create-tealina`.
