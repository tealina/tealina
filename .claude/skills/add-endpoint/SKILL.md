# Add an endpoint to the scaffold templates

Use this when adding or changing a demo route under
`packages/create-tealina/template/server/**/src/api/v1/`. Read `AGENTS.md` first.

## The six trees

A route exists once per framework and per mode:

```
template/server/{express,fastify,koa}/src/api/v1/<method>/<route>.ts
template/server/{express,fastify,koa}-js/src/api/v1/<method>/<route>.js
```

They are translations, not copies. TypeScript annotates the handler directly; JavaScript uses
JSDoc. Keep both readable as the same file.

## Steps

1. Pick the method directory (`get/`, `post/`, …) and write the handler in **all six trees**.
   - TypeScript: `const handler: OpenHandler<Payload, Response> = …` then
     `export default openApi(handler)` (or `authedApi`).
   - JavaScript: `@typedef` for payload shapes, then
     `/** @type {OpenAPI<Payload, Response>} */`. `OpenAPI` comes from `types/alias.d.ts`.
   - Use `interface`/`@typedef` for payload shapes, not inline object types: the document
     generator records the declaration name.
   - JSDoc comments become API documentation; `//` comments do not.
2. Update the barrels in each tree. `create` copies them as-is; it does not run `align`, so a
   handler missing from the barrel is silently unrouted in scaffolded projects.
   - `src/api/v1/<method>/index.<ext>` gets one line alongside the existing ones.
   - `src/api/v1/index.<ext>` only changes for a new method directory.
   - Keep the generated header (`// @generated by tealina — do not edit.`) and sorted keys.
3. If the route adds a file, name it in `src/template-manifest.ts` (`kFrameworkSourceFiles`) and
   add it to **every** framework's list — the manifest is the only list of shipped files.
4. If the route changes what the scaffolded demo needs (for example a payload type), keep the
   web demo page in step (`template/web*/src/main.demo.*` calls `req.get('health')`).
5. Verify:

   ```bash
   vp check
   pnpm -F create-tealina test
   TEALINA_E2E=1 pnpm -F create-tealina test   # slow; real install and request
   ```

   `test/template-parity.test.ts` will fail if one tree is missing a file;
   `test/init-manifest.test.ts` will fail if the manifest and template disagree.
6. If the endpoint changes what users see in a generated project, add a changeset for
   `create-tealina`.
