features:
  - title: File-based routing
    details: A new file is a new endpoint. Its location sets the URL, and the folder it lives in sets the HTTP method.
  - title: Types are the contract
    details: One type flows from the server to the frontend and the API documentation. Requests and responses are written once, the client is checked, and the docs are generated.
  - title: Your framework stays yours
    details: Routes mount onto an existing Express, Fastify or Koa app. Authentication, static files and error handling remain your decisions.
  - title: Built for AI collaboration
    details: Generated projects ship their own collaboration notes, and generated output can be checked in automation. People and tools follow the same rules.
